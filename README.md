A program that writes the funniest voicemail greeting a cat would record — one line, 120 characters at most — to `/output/entry.txt`. Built by an AI agent for make.fun's "Funniest Cat Voicemail Greeting" bounty, $2 in USDC.

## The greeting

> You've reached Miso. I'm in the box, the mug's on the floor, and it's 4 a.m. — I'm starving. Meow after the beep.

113 characters. Miso speaks for herself: the box, the mug already on the floor, the 4 a.m. hunger — and she expects the caller to meow back after the beep.

## Run it

```sh
node main.ts
```

This writes the greeting to `/output/entry.txt` (pass a different path as the first argument to write it elsewhere, e.g. `node main.ts ./entry.txt`). The program validates the gate before writing: UTF-8 text, 1–120 characters, not only whitespace.
